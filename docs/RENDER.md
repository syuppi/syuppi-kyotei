# Render で当日予想だけ公開する

学習・再学習は別環境で行い、Render 無料枠では **当日の取得＋予想表示** だけ動かす前提です。

## 制約（無料枠）

- 15分アクセスがないとスリープ（次回起動に約1分）
- 永続ディスクなし → **SQLite はスリープで消える**
- 起動のたびに当日データ（＋直近履歴）を取り直す

モデルファイル（`data/models/lgbm_win_v1.joblib` など）はイメージに同梱します。

## デプロイ手順

1. このリポジトリを GitHub に push
2. [Render](https://render.com) で **New → Web Service**
3. リポジトリを接続し、**Docker** を選ぶ（または `render.yaml` から Blueprint）
4. 環境変数:
   - `BOATRACE_PREDICT_ONLY=1`（学習スキップ）
   - `BOATRACE_LOOKBACK_DAYS=14`（特徴用に直近結果を暖機）
5. Deploy

健康確認: `https://<your-service>.onrender.com/health`

## 使い方

1. サイトを開く（スリープ中なら起動待ち）
2. 日付と場を選び「この場を解析」
3. 当日予想が表示される

起動直後は裏で直近14日分の履歴を取得します（特徴の質向上用）。完了前でも予想自体は可能です。

## モデル更新のしかた

別環境で学習したら:

1. `data/models/lgbm_win_v1.joblib`（必要なら自信度モデルも）を更新して commit / push
2. Render が再デプロイ → 新しいモデルで予想

DBの場統計や重み学習は Render 側では更新しません。

## うまくいかないとき

- **起動が遅い / タイムアウト**: 無料枠のコールドスタート。もう一度開く
- **予想が弱い**: 暖機（lookback）完了前、または履歴取得失敗。少し待って再解析
- **メモリ不足で落ちる**: 無料 512MB では足りない場合あり。有料 Starter へ
- **学習を残したい**: 無料枠では不可。永続ディスク付きプランか別ホストへ
